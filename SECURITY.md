# Security

This project supplies local instructions, installation tools and browser checks. Read scripts before
running them. Host permissions determine access; the harness is not an isolation boundary.
The installer preserves existing files and reports conflicts. Static route checks are not proof of
native activation, hidden guidance isolation, browser safety or model compliance. Only render input
appropriate to your project. Nothing installs globally, stores credentials or publishes remotely.

Use the repository's private vulnerability reporting when available. Otherwise open a non-sensitive
issue requesting a private reporting route. Do not post credentials or exploit details publicly.
No reporting address or response-time guarantee is asserted.
