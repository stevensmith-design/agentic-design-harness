# Design decisions

Newest first. One entry per genuine decision or intentional exception.

Record a decision when a later reader would otherwise re-litigate it, or would
reasonably think the code was a mistake. Do not record routine work.

Format:

```
## YYYY-MM-DD · <the decision, in one line>
**Why:** the reason, including what was rejected.
**Applies to:** where this binds.
**Provisional?** yes/no — if yes, what would settle it.
```
