# Component index

**Compact by design.** One row per component — enough to know whether a thing
exists and where, not enough to need loading the whole file to find out.
Detail lives in the implementation.

**Look here before building any component.** A second implementation of
something already in this table is the defect this project cares most about.

| Component | Path | Variants | States | Status |
|---|---|---|---|---|
| _(none yet)_ | | | | |

**Status:** `current` · `provisional` (in use, not settled) · `deprecated`
(do not use in new work; says what replaces it) · `planned`.

**States** are the ones actually implemented, from: default · hover ·
focus-visible · active · disabled · loading · error · success. An interactive
component missing focus-visible, active or disabled is incomplete, not minimal.

Add a row when a component becomes reusable — used twice, or built to be. Do
not pre-register.
